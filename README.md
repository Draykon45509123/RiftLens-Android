# RiftLens Android · 0.6 experimental

Compilación Android con vista previa de cámara y calculadora de enfriamientos para **repeticiones y entrenamiento**.

## Funciones
- Vista previa de cámara posterior, con permiso explícito.
- Enfriamiento estimado a partir del tiempo base y aceleración confirmada: C = base × 100/(100 + AH).
- Sin anuncios, cuentas ni transmisión de imágenes.
- **No detecta automáticamente campeones, objetos ni habilidades.** No rastrea cooldowns de enemigos en partidas activas.

Esta versión mínima es distinta al prototipo 0.5 con catálogo y análisis experimental. Se publicó para establecer primero una compilación reproducible y un instalador.

## APK
Abre Actions > Build RiftLens APK > última ejecución > Artifacts > RiftLens-APK-debug. 
Descomprime el archivo descargado e instala `app-debug.apk` en Android 8.0+.
Los resultados de la compilación y las pruebas físicas deben verificarse; no están garantizados de antemano.
